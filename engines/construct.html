Construct 3

Визуальный конструктор 2D-игр, работающий в браузере

Описание

Construct 3 — это визуальный конструктор игр, который работает прямо в браузере и не требует установки. Вся логика игры строится на системе событий: разработчик выбирает условие и действие, а движок сам выполняет нужные операции. Программировать на классическом языке не нужно, что делает Construct идеальным выбором для новичков и художников, которые хотят быстро превратить свою идею в работающий прототип.

Характеристики

Разработчик Scirra
Тип 2D
Язык программирования Event System, JavaScript
Цена Бесплатный триал, подписка от $12/мес
Платформы экспорта Windows, macOS, Linux, Android, iOS, Web
Сложность Низкая

Плюсы и минусы

Плюсы

  • Не требует программирования
  • Работает прямо в браузере
  • Очень быстрый старт проекта
  • Хорошо подходит для мобильных игр

Минусы

  • Только 2D, 3D-игры не сделать
  • Платная подписка для публикации
  • Ограничения для крупных проектов
