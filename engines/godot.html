Godot

Полностью бесплатный движок с открытым исходным кодом

Описание

Godot — бесплатный игровой движок с открытым исходным кодом, разрабатываемый сообществом. Не требует лицензионных отчислений и не имеет ограничений по коммерческому использованию. Поддерживает как 2D, так и 3D-графику, работает на слабых компьютерах. Основной язык программирования — GDScript, похожий на Python. Благодаря простоте и лёгкости Godot часто рекомендуют новичкам для первой игры.

Характеристики

Разработчик Godot Engine Community
Тип 2D / 3D
Язык программирования GDScript, C#, C++
Цена Полностью бесплатно, без роялти
Платформы экспорта Windows, macOS, Linux, Android, iOS, Web
Сложность Низкая

Плюсы и минусы

Плюсы

  • Абсолютно бесплатный без скрытых условий
  • Открытый исходный код
  • Лёгкий и быстрый, работает на слабых ПК
  • Простой язык GDScript

Минусы

  • Меньше готовых ассетов, чем у Unity
  • Слабее инструменты для 3D-графики
  • Меньше вакансий на рынке труда
