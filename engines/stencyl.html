Stencyl

Визуальная среда для 2D-игр на основе блоков

Описание

Stencyl — визуальная среда для создания 2D-игр, вдохновлённая Scratch. Логика игры собирается из блоков, как в конструкторе: пользователь перетаскивает готовые элементы и соединяет их между собой. Это позволяет создавать игры без знания программирования. Для опытных разработчиков доступен язык Haxe, на котором можно писать собственные расширения. Stencyl отлично подходит для школьников, студентов и всех, кто хочет начать с самых простых проектов.
