Unity

Универсальный движок для 2D и 3D-игр от Unity Technologies

Описание

Unity — один из самых популярных игровых движков в мире. На нём созданы тысячи игр для ПК, мобильных устройств, консолей и веб-браузеров. Движок поддерживает как 2D, так и 3D-графику, имеет мощный редактор и огромное сообщество. Основной язык программирования — C#. Unity отлично подходит как для инди-разработчиков, так и для крупных студий.

Характеристики

Разработчик Unity Technologies
Тип 2D / 3D
Язык программирования C#
Цена Бесплатно (Personal), от $2200/год (Pro)
Платформы экспорта Windows, macOS, Linux, Android, iOS, Web, консоли

Плюсы и минусы

Плюсы

  • Огромное сообщество и много обучающих материалов
  • Asset Store с тысячами готовых ассетов
  • Поддержка всех популярных платформ
  • Бесплатная версия для небольших проектов

Минусы

  • Большой размер сборки по сравнению с лёгкими движками
  • Сложная система рендеринга для новичков
  • Плавающая производительность на слабых устройствах
