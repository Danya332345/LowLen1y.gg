UE

Unreal Engine

Мощный 3D-движок от Epic Games для AAA-проектов

Описание

Unreal Engine — один из самых мощных игровых движков в мире, созданный компанией Epic Games. Изначально разработан для шутеров от первого лица, но сегодня используется в самых разных жанрах. Движок известен своей фотореалистичной графикой, продвинутой системой освещения и физики. Разработка ведётся на C++ или через визуальную систему Blueprints, которая позволяет создавать логику без написания кода.
