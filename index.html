Популярные движки

Наведи курсор на карточку, чтобы увидеть краткое описание. Кликни — чтобы открыть полный обзор.

U

Unity

Универсальный движок для 2D и 3D. Язык: C#. Подходит для мобильных и ПК-игр.
UE

Unreal Engine

Мощный 3D-движок от Epic Games. Язык: C++ и Blueprints. Для AAA-проектов.
G

Godot

Полностью бесплатный движок с открытым кодом. Язык: GDScript. Отлично для новичков.
GM

GameMaker

Движок для 2D-игр. Язык: GML. Простой старт, подходит для инди-проектов.
C3

Construct 3

Визуальный конструктор 2D-игр. Программирование не требуется. Работает в браузере.
RPG

RPG Maker

Специализированный движок для японских ролевых игр. Минимум программирования.
CE

CryEngine

Профессиональный 3D-движок с фотореалистичной графикой. Язык: C++ и Lua.
D

Defold

Лёгкий бесплатный движок для 2D. Язык: Lua. Хорошо подходит для мобильных игр.
GD

GDevelop

Бесплатный конструктор без кода. Идеален для самых первых проектов.
S

Stencyl

Визуальная среда для 2D-игр на основе блоков. Лёгкий старт без кода.
